{% comment %} The four strands of the lab, and the double meaning of "NN": neural networks (methods) and brain networks (application). Label positions are the computed centroids of each circle's exclusive region, so all four sit symmetrically: (129,104) (391,104) (129,366) (391,366). Two-line labels straddle that point by ±11. Hit-testing is done in script, geometrically: the rings are fill="none", so the browser only registers them along the 2.5px stroke, and where four strokes cross whichever is painted last wins. Instead, `.venn-surface` (a transparent rect covering the whole viewBox) catches the pointer and the script works out which circles actually contain that point — so the overlap regions light up every circle they belong to. data-cx / data-cy / data-r on each group are what the script reads; they must stay in step with the below them. The keys hf / lf / nn / bn are the same ones the overview text uses in _data/research.yml. Note the geometric limit: four equal circles in a square produce 13 of the 15 possible regions. The two diagonal pairs — here lf+bn and hf+nn — have no region of their own, so no text can be attached to them. {% endcomment %}
